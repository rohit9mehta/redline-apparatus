# Results

See [results.md](results.md) for the rendered tables.

- `metrics_summary.json` — the benchmark's own scoring output (leaderboard rows, per-turn/side/category breakdowns, diagnostics)
- `surgicalness.json` — behavioral profile per actor (benchmark metric code, expert filtered to the represented side's attorney layers)
- `redlines/{baseline,apparatus}/<task>.docx` — all 16 final redlines with native tracked changes; open in Word's Review pane
- `apparatus_trail/<task>/` — per-task rule cards (verbatim-audited quotes), triage + dispositions, and final gate report

Contract documents derive from the RedlineBench dataset (crosbylegal/RedlineBench, CC-BY-4.0).
